# Collection, search and cart pages

[Back to the guide](index.md)

## Collection page

Choose *Collections > Default collection* in the editor's page selector.

- **Look**: **Lookbook**, **Split**, **Mosaic** or **Index**. Every look
  uses your theme's colors, fonts, buttons and product cards.
- **Products per page**.
- **Picture shape**: **Rectangle**, or a shape such as **Arch**, **Circle**
  or **Diamond**. The **Index** look keeps plain pictures.
- **Show the vendor** under each product.
- **Show the heading** and **Heading**: replace the collection's own name on
  this page, or hide it from view (screen readers and search engines still
  read it).
- **Show the collection image**: the collection's own picture beside its
  heading.

### Filters and sorting

- **Let shoppers sort**: by price, name, date and best selling.
- Filters (price, availability, product type, vendor, color, size and more)
  are chosen in the free *Shopify Search & Discovery* app. The page shows
  whichever filters you set up there.
- **Price bands**: quick price choices beside the price filter, such as
  `25, 50, 100`. Write them in your own currency, separated by commas.

## Collections list page

The page listing all your collections uses the **Collection tiles**
section. Choose *Collections list* in the page selector. On this page it
shows every collection; **Collections per page** sets how many per page.
See [Collection tiles](sections.md#collection-tiles).

## Search page

Choose *Search* in the page selector. It has the same **Look**, **Picture
shape**, sorting and filter settings as the collection page, plus:

- **Results per page**.
- **Suggest products from**: a collection shown when a search finds
  nothing, so the shopper still has somewhere to go.

What the search looks through (**Search across**) and the suggestions while
typing are set in Theme settings, under **Search**.

## Cart page

Choose *Cart* in the page selector.

- **Look**: **Receipt**, **Editorial** or **Compact table**.
- Shoppers can change quantities and remove items. Discounts, the taxes
  note and subscriptions are shown for each item and in the total.
- The checkout button stays in reach on long carts.
- Express checkout buttons (Shop Pay, Apple Pay and others) appear when
  your shop offers them.

Set in Theme settings, under **Cart**:

- **Let shoppers add a note**: a note box sent with the order.
- **Empty cart suggestions**: products shown when the cart is empty.
- **Show vendor** under each item.

Apps can add blocks to the cart page, and the **Custom Liquid** block takes
code an app asks you to paste.
