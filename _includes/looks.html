{%- comment -%} A component's looks: one button per look, and for each look a computer and a phone screenshot side by side. Pictures live in assets/images//---light.webp (task 5.3). A look that moves also has a clip, --desktop-light.mp4; when that file is published the computer picture becomes a clip that starts when pressed, with the still as its cover. The cover is set from data-poster by assets/guide.js when the clip nears the screen, because a poster attribute cannot be lazy-loaded. Params: folder the picture folder, e.g. "sections" file the file name start, e.g. "featured-products" name the component's name, used in the picture descriptions looks look names separated by commas, e.g. "Shelf,Arc". A name may carry its file part after a tilde, e.g. "Split: words beside the box~split" about optional, what each look shows, separated by "|" in the same order as looks; added to each picture's description plain optional, "true" for a component with one look only: the file names have no look part (-desktop-light.webp) and there is no switcher Example: {% include looks.html folder="sections" file="featured-products" name="Featured products" looks="Shelf,Arc" about="Products standing on shelves.|One curved row." %} {%- endcomment -%} {%- assign looks = include.looks | split: ',' -%} {%- assign abouts = include.about | split: '|' -%}
